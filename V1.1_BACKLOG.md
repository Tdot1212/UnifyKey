## Phase 3 follow-ups (BYOK architecture)
- **Multi-account API keys per provider.** Currently a single Keychain entry (`account = "apiKey"`) is reused across all 4 providers. Switching provider while keeping an old key produces silent 401s with no UI cue that the *key* is wrong rather than the *network*. Options: (a) clear the key on provider switch, (b) per-provider keys (`apiKey_openai`, `apiKey_anthropic`, etc.), (c) format-mismatch warning at switch time.
- **API key format validation.** OpenAI keys start with `sk-`, Anthropic with `sk-ant-`, Gemini with `AIza`. Currently any non-empty string is accepted in `APIKeyInputView` and only fails at first API call. Add a per-provider regex check + paste-trim.
- **Finish KeychainHelper → SharedKeychain migration.** `KeychainHelper` is described in source as "legacy wrapper... Kept for backward compatibility." Either delete the wrapper and call `SharedKeychain` directly, or pick `KeychainHelper` as the canonical public API and bury `SharedKeychain` as private implementation.
