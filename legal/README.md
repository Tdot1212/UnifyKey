# UnifyKey Legal

This folder hosts the privacy policy and terms of service for UnifyKey.

## Hosting via GitHub Pages

Once pushed to `https://github.com/Tdot1212/UnifyKey`, enable GitHub Pages in repo Settings → Pages:
- Source: Deploy from branch `main`
- Folder: `/legal`
- The site will be live at `https://tdot1212.github.io/UnifyKey/`

URLs to use in App Store Connect:
- Privacy Policy: `https://tdot1212.github.io/UnifyKey/privacy.html`
- Terms of Service: `https://tdot1212.github.io/UnifyKey/terms.html`

## Updating

When privacy practices or terms change:
1. Update the relevant `.html` file in this folder
2. Bump the "Effective:" date
3. Commit and push — GitHub Pages auto-rebuilds in a few minutes
